The Amazing Pangolin

Project Description

This project is a simple HTML webpage about the pangolin — one of the most unique and fascinating animals in the world.

The page includes:

* A heading and descriptive paragraph
* Interesting facts about pangolins
* Multiple images of different pangolin species
* Basic HTML structure and layout styling

The goal of this project is to practice:

* Writing structured HTML
* Using headings, paragraphs, and lists
* Displaying images from external sources
* Organizing content clearly on a webpage

Technologies Used

* HTML5
* Basic CSS (for layout and styling)
* CodePen online editor

Features

* Informative description about pangolins
* Bullet-point list of interesting facts
* Centered and grouped images
* Clean and readable layout

Why Pangolins?

Pangolins are the only mammals fully covered in scales.
They play an important role in the ecosystem by controlling insect populations.

Unfortunately, they are also one of the most trafficked mammals in the world, which makes awareness and education about them very important.

How to View the Project

1. Open the CodePen link.
2. If images do not display in preview mode, open the project in 
Debug Mode.
3. Make sure you are connected to the internet (images are loaded externally).
